# luke-look

Personal portfolio for Luke Cheng, a front-end developer in Taipei.

This repository is a minimal Next.js starter so the site can build and deploy on Vercel. The home page is a placeholder. Real content and design will be added later.

## Stack

- [Next.js](https://nextjs.org) App Router
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

## Deploy

Connect this repository to Vercel and deploy the `main` branch. The app uses the framework defaults, so no `vercel.json` is required.
